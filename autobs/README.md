# autobs — Reader 书源自动配置工具

输入**一本书的目录页网址**，自动分析网页结构并生成可直接导入
[Reader](https://github.com/binbyu/Reader)（binbyu 版）的书源文件，
免去手工配置 xpath 的麻烦。

## 环境要求

- Python 3.8+
- 依赖：`pip install requests lxml`

## 用法

```bash
# 生成书源（最常用）
python autobs.py "https://www.dmxs2.com/book/lsrsdspj.html"

# 指定书名/书源名/输出文件
python autobs.py "http://www.pksge.la/wudiliuhuangzi/" --title 无敌测试皇 --name 平凡文学 -o bs_pksge.json

# 校验一个书源文件是否真的能跑通（模拟 Reader 的 搜索→章节→正文 流程）
python autobs.py --verify bs_pksge.json --book 无敌测试皇

# 直接按书源把整本书抓成 txt（断点续抓；连载书重跑一次只补新章节）
python autobs.py --download bs_sharpbro.json                  # 单书模式书源
python autobs.py --download bs_pksge.json "http://www.pksge.la/wudiliuhuangzi/"  # 普通书源需带书页URL
```

**txt 导出说明**：输出为 UTF-8（带 BOM）文本，正文按 `<br>` 还原段落换行，
自动剔除常见防阅读器水印行（`👉👉 当前浏览器转码失败…`、`退#出#阅#读#模#式` 等）。
站点有 Cloudflare 等防护导致 Reader 无法在线阅读时，这是最佳退路——
工具的浏览器特征请求通常仍能正常抓取。

生成成功后，在 Reader 中导入：
**设置 → 在线小说 → 书源管理 → 导入** → 选择生成的 `bs_*.json`
（导入会自动与已有书源合并），然后按书名搜索即可阅读。

## 自动完成了什么

| 配置项 | 自动策略 |
| --- | --- |
| 章节列表 xpath | 找页面中"大量重复、链接规律"的链接组，用父元素 class/id 或公共祖先生成 xpath，兼容 `dd` 未闭合等畸形 HTML |
| 章节列表分页 | 跟随"下一页"验证第二页确有新章节后才启用 |
| 章节正文 xpath | 在两个采样章节页上按"干净文本"（剔除 script/style）+ id/class 线索 + 链接密度 + 杂质惩罚评分，取跨页稳定的最干净单容器（Reader 只取第一个匹配节点） |
| 正文分页 | 跟随"下一页"直到关键字消失（≥6页不收尾则放弃，防死循环） |
| 搜索 URL | 解析首页搜索表单（自动跳过 CSRF token，GET/POST 两种提交方式都试），并用杰奇/EmpireCMS 等常见搜索端点兜底 |
| 关键字编码 | UTF-8 / GBK 各真实搜索一次，命中者胜 |
| 搜索页 xpath | 用"书名前两个字"泛化搜索得到多结果页，定位结果行的共同结构并去掉行号位置谓词（Reader 文档"样例一"的自动化），再回验书名搜索页确实能找到本书 |
| 不完整目录页 | 书页只显示"最新章节"时，自动跟随"目录/全部章节"链接换取完整章节列表（生成"书籍主页解析"跳转配置） |
| Reader 仿真预检 | 用 Reader.exe 内置的真实 UA（Chrome/67）、无 Cookie、不跟随跳转复验目录页和章节页，Cloudflare/WAF 挑战页会在导入前暴露 |

生成前所有规则都会经过真实请求验证，验证不过的项会在报告中标出。

### 单书模式

当站点搜索接口被 WAF 拦截、或站点根本没有搜索功能时，会自动退化为**单书模式**：
把"搜索"指向本书书页本身——在 Reader 里搜索任意关键词都只返回这本书，
不影响章节解析、正文阅读和连载更新。书源名直接使用书名。

## 局限（这些情况下需要手工补充或无法使用）

- **JS 渲染页面 / 强反爬（验证码、JS 挑战）**：Reader 本身也读不了这类站点。
  （搜索接口被拦截而书页可读的场景，已由单书模式覆盖。）
- **搜索结果匹配作者或简介但不回显书名的站点**：行定位依赖书名搜索页回验，
  个别站点可能需要手工微调搜索页 xpath。
- 正文里站方插入的水印文字（如 `#阅#读#模#式`）：请在书源管理的
  "文本过滤"中自行添加关键字或正则过滤。

## 退出码

- `0`：全部关键项成功
- `1`：致命失败（无法识别章节/正文，或 --verify 未通过）
- `2`：章节/正文成功但搜索配置未能自动生成
- `3`：Reader 仿真预检失败（站点对 Reader 客户端有防护，导入也用不了）
